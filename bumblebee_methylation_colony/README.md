## Project

Reproductive workers in *Bombus terrestris* diverge from a colony-specific DNA methylation landscape. This project characterises genome-wide methylation across colonies and identifies loci where reproductive workers depart from the colony baseline, with the aim of understanding how epigenetic state tracks or predicts reproductive status.
